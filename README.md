# ML Zoomcamp 2026

Homework for [Machine Learning Zoomcamp](https://github.com/DataTalksClub/machine-learning-zoomcamp).

## Setup

```bash
uv python pin 3.11
uv venv --python 3.11
uv pip install -r requirements.txt
```

Run

```bash
uv run jupyter notebook
```

Then open the corresponding `.ipynb` file.
